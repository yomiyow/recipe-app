# Recipe App

A mobile application that allows users to browse, search, and explore different recipes in an easy and visually appealing way.

## ✨ Features
- Browse recipes by category (Beef, Chicken, Dessert, etc.)
- View detailed recipe information
- Mark recipes as favorites
